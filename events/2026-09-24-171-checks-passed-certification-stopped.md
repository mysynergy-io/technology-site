title: 171 checks passed. Certification still stopped.
---

The final candidate passed every independent technical check.

Certification stopped anyway.

The review mandate named a required "six-property closure test." Nobody could find a definition of the six properties. The phrase had been carried forward from an architecture document where the test was named but never enumerated.

The certifier could have invented six plausible properties, run them and moved on.

It refused.

That is the moment the governance model became real for us. Unknown did not become pass just because the code looked good. An undefined requirement was treated as undefined.

The object did not change before certification resumed. The authority around the test did.
