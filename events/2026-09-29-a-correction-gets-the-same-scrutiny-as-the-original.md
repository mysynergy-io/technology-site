title: A correction gets the same scrutiny as the original
---

A reviewer rejected a change. We corrected it and resubmitted. The correction reintroduced the same problem it was written to remove.

That happened more than once this month. One fix had to be fixed twice.

A correction is written by whoever has just finished being wrong about that exact area, in the relief of finally understanding it. That is the worst moment to be trusted and the usual moment to be waved through.

Corrections now get the same independent review as the work they correct. Every defect we found in a fix was found by someone who did not write it.
