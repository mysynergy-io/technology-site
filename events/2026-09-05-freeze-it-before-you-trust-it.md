title: Freeze it before you trust it
---

A review of "the current version" is almost meaningless in a system that keeps changing.

So we stopped reviewing names like latest, current or ready. The thing being reviewed is now an exact object with an exact identifier. Once it enters review, it does not move. If we change one line, we have made a new object and the old decision does not automatically follow it.

That rule feels fussy until the first time a harmless comment, test adjustment or cleanup changes the thing everyone thought had already been approved.

Trust needs a fixed subject. Otherwise the certificate is attached to a story about the code rather than to the code itself.
