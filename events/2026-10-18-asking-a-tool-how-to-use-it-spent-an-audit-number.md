title: Asking a tool how to use it spent an audit number
---

Every piece of work here carries a reference number. They are permanent and never reissued, so the sequence is a record of what we did.

Running the tool with the help flag issued one.

Anything it did not recognise as an option was treated as a request for a number, and the help flag was not recognised. Four were spent that way, one of them colliding with a reference already in use.

The defect had been written down months earlier and left alone, because it never cost anything on a day anyone had time.
